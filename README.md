🌌 Concept

*Diapason Cristal* est un projet hybride où le violon devient une interface
sensible, une boule de cristal vibrante. Tu joues des *harmoniques* sur le
violon, dont le *fingerboard* s'appelle *diapasón* en espagnol. Tu utilises
aussi un *diapason*(tuning fork) comme symbole d'accord et de fréquence. Le
violon devient un capteur, un guide, un outil d’exploration des lieux
invisibles.
🧠 Technologies & Outils

   -

   🎼 *Violons & harmoniques* : source sonore et vibratoire
   -

   💎 *Ruby / Python* : langages numériques pour explorer l’environnement
   -

   🧭 *Frameworks modulables* : selon l’humeur et les besoins créatifs
   -

   🖼️ *Affiche & logo* : identité visuelle en cours de création
   -

   🗓️ *Jour de performance* : chaque numéro est lié à un jour précis
   -

   🧑‍💼 *Carte de visite* : ton nom + ton métier = ton empreinte artistique

🎭 Mode d’emploi

   1.

   *Choisis ton jour* de la semaine pour performer.
   2.

   *Prépare ton numéro* : une performance courte, intense, sans trop parler.
   3.

   *Affiche ton activité* avec une carte de visite claire (nom + métier).
   4.

   *Crée une affiche* ou une publicité avec ton logo.
   5.

   *Ne finalise pas trop vite* : la maquette est en cours, et c’est très
   bien ainsi.
   6.

   *Change de framework ou de langage* si l’inspiration te le demande.
   7.

   *Ne montre pas tous les prix* : mais mets en avant ton *produit star*.

🌟 Produit Star

🎯 *Cristal Explorer* — un module Python interactif pour cartographier les
harmoniques dans l’espace autour du violon. Il capte les fréquences, les
traduit en visuels, et les relie à des lieux ou des émotions
